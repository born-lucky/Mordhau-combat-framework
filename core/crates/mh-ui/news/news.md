# **Mordhau Rewrite**

A from-scratch Rust and Bevy rewrite of MORDHAU that runs on the game files from your own install. Rules, menus and HUD are ported from the shipped game's code and Blueprints, not reinvented.

## **CURRENT STAGE**
* Stage 1: UI. Main menu, settings, local match, HUD and scoreboard, judged side by side against the real game
* Stage 2: Character creator. Mercenaries, equipment, preview doll
* Running alongside: first-person combat feel

This news panel is the game's own widget. It reads this local document in place of the online news feed.
