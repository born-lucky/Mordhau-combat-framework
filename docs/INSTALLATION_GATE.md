# Original-install verification

The separate `mh-install` crate is a preflight checker. It never downloads game
files, attaches to a game process, launches the original game, copies assets, or
claims Steam ownership. The expected game hash is fixed in production; unit tests
exercise a private helper with synthetic fixtures without a runtime bypass.

Both `MordhauRewrite` and direct `mordhau` startup run the gate before starting a
game process or initializing Bevy. Missing or incompatible files stop startup.
Runtime arguments that select stub/core/golden/network alternatives are rejected.
A standalone `verify-install` command checks installation compatibility only and
explicitly reports that it does not check readiness of the local import cache.

Installation selection: `MORDHAU_DIR`, otherwise the normal default Steam folder.
Required executable: `Mordhau/Binaries/Win64/Mordhau-Win64-Shipping.exe`.
Expected SHA-1: `dfe6f4fcb8e8a4603198025e13438b10062b0c4a`.
Expected original build: `702625635`. Present installation version markers must
match. EXE and PhysX library DOS/PE headers must identify AMD64 PE32+.

The initial gate requires a nonempty `pakchunk0-WindowsClient.pak` and five
original PhysX DLLs. It does not authenticate every pak/DLL byte. Actual pak
parsing and combat loading can still fail, and those errors stop startup.
Installation-file presence and compatible hashes are not proof of purchase.

Local cache selection: `MORDHAU_LOCAL_DATA`, otherwise
`%LOCALAPPDATA%/mordhau-rewrite-rust/v1/<original-EXE-SHA1>`.
No cache is generated by this checker; the consumer importer remains unfinished.
The selected cache must contain:

- `data_gen/spec`: index, fields, rules, sources and all indexed entity files.
- `extract/native/rdata.tsv` and required motion ancestry headers under `types/`.
- `shaders/ue_tint.wgsl`, `shaders/uepost.wgsl`, and `shadow_capsules.json`.
- `state/physics/mh_physx.dll`, privately built under applicable third-party rights.

Canonical paths must stay inside the selected installation/cache. Index paths
cannot escape via absolute paths, parent traversal, or symlinks. JSON schema,
required entity kinds and counts, and native-record presence are checked before
startup. The runtime then validates its actual spec and combat initialization.
This is not an authenticity signature for locally generated data.

After validation, explicit environment paths point the runtime to the user's
cache, so compiled developer-workspace paths are not fallback data sources.
Local imports and game files must not be committed, attached to issues, or bundled.
